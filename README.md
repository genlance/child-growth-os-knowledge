# 晖爸 0-18 岁成长知识库

> 每天说一句话，AI 帮你保存孩子 18 年的成长故事。

这是给家长使用的 AI 育儿成长助手知识库。你可以把它理解成一个会帮你整理孩子成长记录的助手：你平时像发微信一样说一句话、发一张照片，它会帮你慢慢整理成成长日记、照片档案、成长时间轴和每月育儿知识概览。

它不是替代父母，也不是替代医生。它更像一个耐心的家庭记录员，帮你把那些很容易散落的小瞬间保存下来。

## 适合谁

- 刚成为新手爸妈，想轻松记录孩子成长。
- 平时拍了很多照片，但后来很难找、很难整理。
- 想把孩子 0-18 岁的重要瞬间长期保存下来。
- 想让 AI 帮忙把文字、照片、健康记录、喂养睡眠等信息整理成档案。
- 不想一开始就折腾复杂系统，希望先从本地简单记录开始。

## 能做什么

- 像微信聊天一样记录孩子每天的小事。
- 先回你一句“收到，我先帮你记下”，不会让你一直等。
- 保存照片，并把照片关联到对应的成长日记、健康记录或重要事件。
- 每天整理成长日记，晚上提醒你看看有没有要补充的细节。
- 按孩子月龄推送轻量育儿知识。
- 把旧照片、旧日记、以前的表格先扫描成待确认清单，再导入。
- 后续可以生成成长时间轴、专题照片墙和年度成长报告。
- 可以先保存在本地，以后需要时再同步到飞书。

## 第一次怎么用

如果你使用的是 Codex、QClaw、OpenClaw、WorkBuddy 这类支持 Skill 安装的 agent，可以先安装主控助手：

```text
请安装晖爸 child-growth-os 育儿成长助手：
https://github.com/genlance/child-growth-os-knowledge/tree/main/skills/child-growth-os
```

安装成功后，如果 QClaw 没有自动进入引导流程，请在对话框里继续发送这一句：

```text
开始使用晖爸 child-growth-os 育儿成长助手
```

或者发送更口语一点的：

```text
我是第一次使用，先帮我建立孩子成长档案。
```

然后助手会问你：

```text
你是第一次使用，还是以前已经有 ChildGrowthOS 育儿资料文件夹？

回复：
1. 第一次使用
2. 我已经有旧资料文件夹
```

如果你是第一次使用，建议回复：

```text
1，D盘
```

意思是：选择方案 1「简单本地保存」，并把孩子资料放到 D 盘。你也可以回复 `1，E盘` 或 `1，F盘`，选择你电脑里空间比较大的非系统盘。

如果你只回复 `1`，助手应该继续问你想放在哪个盘，不能先在 C 盘临时创建资料夹。

微信/ClawBot 可以等本地档案建好后再连接。你可以对助手说：

```text
我想通过微信记录孩子成长，请帮我连接 ClawBot。
```

```text

```

```text
今天去看医生了，我发一下医生开的单子照片，帮我存到健康档案里。
```

```text

```

```text

```

助手会先回复收到，再慢慢整理和保存，不会让你一直等着没反应。

平时它会尽量像一个热心的育儿助手一样说话，不会动不动把文件路径、JSON、校验值这些技术细节发给你。你想看保存明细时，可以单独说：

```text
把保存明细发我看看。
```

## 资料保存在哪里

确认保存位置后，助手会创建一个 `ChildGrowthOS` 文件夹，里面放你的成长记录、照片和数据文件。

注意：技能本身可能会安装在 QClaw 的 C 盘目录里，这只是程序文件；真正重要的是孩子的成长资料。成长资料不要默认放 C 盘，建议放在非系统盘，比如：

```text
D:\ChildGrowthOS
E:\ChildGrowthOS
```

如果你的电脑有 D 盘或 E 盘，助手会优先建议放到非系统盘。只有电脑没有其他盘，或你明确同意，才放到 C 盘。

确认保存位置前，助手不应该创建任何资料夹。如果你看到它直接创建到了 C 盘，可以让它停止，并回复：

```text
不要放 C 盘，请改到 D:\ChildGrowthOS。
```

即使只是“临时文件夹”，也不应该先建在 C 盘再删除。保存位置确认前，助手只能说明建议路径，不能创建目录。

大致结构是：

```text
D:\ChildGrowthOS/
├── ChildGrowthOS.xlsx
├── data/
├── photos/
├── imports/
├── exports/
└── logs/
```

其中 `ChildGrowthOS.xlsx` 是给你看的表格，应该在资料夹根目录，双击就能打开。`data/` 里的 JSON 文件是给 AI 助手读取的内部数据，不是让家长每天去看的。

每次你通过微信记录孩子，助手都应该同时更新两份：

- `ChildGrowthOS.xlsx`：给你打开查看。
- `data/`：给 agent 后续分析、同步、生成时间轴使用。

如果你发现资料夹里只有 `data/` 和 JSON，没有 `ChildGrowthOS.xlsx`，可以直接对助手说：

```text
请帮我补建 ChildGrowthOS.xlsx，并把已有记录同步进去。
```

你不用一开始理解这些文件。只要记住一件事：

```text
以后换电脑时，把整个 ChildGrowthOS 文件夹复制过去就可以继续用。
```

技能更新不会覆盖你的成长记录、照片、表格和本地资料。

## 照片怎么保存

照片会进入统一的照片资产库，不只是生成一个文件名。

例如：

- 第一次吃西瓜的照片，会关联到当天成长日记和成长时间轴。
- 医生开的单子照片，会关联到健康档案。
- 体检报告照片，会关联到身体成长曲线或健康档案。

这样以后你回看某一天、某个第一次、某次就医记录时，不会只看到文字，也能看到对应照片。

## 每天会推送什么

默认推送节奏：

- 每天 `11:30`：1 条轻量育儿知识，不推大段内容。
- 每天 `21:00`：当天成长日记复盘，问你有没有想补充的细节。
- 每月：按孩子出生日期每满一个月当天 `20:30`，推送一次本月育儿知识概览。

如果你不喜欢这个时间，可以直接通过微信告诉助手：

```text
以后每天育儿知识改成早上9点发。
```

```text
晚上复盘改成22点。
```

## 月龄知识概览是什么

每到孩子出生后的一个新月份，助手会提醒你：

```text
今天是小晖出生后的第 8 个月。

这个月可以重点留意：

1. 辅食种类慢慢增加，继续观察过敏和大便变化。
2. 大运动可能更活跃，可以给孩子更多安全爬行空间。
3. 分离焦虑可能开始变明显，照顾者回应要稳定。

我会结合你平时记录的喂养、睡眠、健康和成长瞬间，帮你把这些观察慢慢整理进孩子档案。

如果你想查看完整版，可以回复：晖爸育儿代码
```

你回复 `晖爸育儿代码` 后，助手会给你完整入口和公开知识库页面。

## 旧资料可以导入吗

可以。

支持这些旧资料：

- 旧照片文件夹
- 微信聊天记录导出
- 以前写的 Word、Markdown、TXT 日记
- Excel 或 CSV 成长记录
- 飞书导出
- 手机相册整理包
- 其他育儿 App 导出的喂养、睡眠、尿片、身高体重、健康记录

导入时不会直接写入正式档案，而是先扫描，生成一份待确认清单。你可以先改日期、标题、说明、标签、是否导入，确认后再正式导入。

你可以这样说：

```text
这是我以前整理的照片文件夹：D:\OldBabyPhotos。请只扫描，先给我待确认清单，不要直接导入。
```

## 本地和飞书怎么选

新手建议先选本地轻量版：

- 不需要配置飞书。
- 资料保存在自己电脑里。
- 后续可以生成时间轴、照片墙和年度报告。
- 以后配置好飞书后，也可以再同步过去。

如果你已经会配置飞书，也可以选择飞书同步或双备份。

如果你飞书里已经有旧表，助手会优先沿用旧表，不会重新新建一套空表覆盖你的旧数据。

## 可选能力

主控助手先负责记录、照片、日记、复盘和轻量知识推送。后续如果你需要，可以再安装其他能力：

- 育儿资料操作员：导入旧资料、生成时间轴、照片墙、年度报告。
- 家庭蒙氏观察教练：观察敏感期、专注、秩序感和家庭环境。
- 家庭英语启蒙教练：规划英语输入、绘本和音频。
- AI 时代通才成长蓝图教练：适合更长期的 3-18 岁能力规划。
- 晖爸育儿知识操作系统：适合深入分析某个育儿问题。

这些都不会自动安装，必须你确认后才会启用。

## 隐私和安全

- 你的孩子照片、成长日记和健康资料默认保存在你自己的电脑或你自己的飞书里。
- 本 GitHub 仓库只保存公开知识库和技能说明，不保存客户私人数据。
- 医疗内容只做记录和提醒，不替代医生诊断。
- 发热、过敏、呼吸困难、脱水、抽搐、外伤等情况，请及时咨询专业医生或就医。
