## 这是什么

这是给家长和育儿 Agent 使用的家庭育儿系统。你可以先从成长记录开始：像发微信一样记录孩子的日常、照片、喂养、睡眠、尿片、健康和成长瞬间，AI 会帮你整理成：

- 每日成长日记
- 照片资产库
- 成长时间轴
- 喂养 / 睡眠 / 尿片 / 健康记录
- 月龄育儿知识推送
- 可导出的长期家庭成长资料

它不是替代父母，也不是替代医生。它更像一个耐心的家庭育儿助手：先把容易散落的小瞬间保存下来，再通过更多 Skills 扩展出照片墙、成长报告、育儿知识、用品选择和学习建议等能力。

## 适合谁

- 新手爸妈，想轻松记录孩子成长。
- 拍了很多照片，但后来很难找、很难整理的家庭。
- 想把孩子 0-18 岁的重要瞬间长期保存下来。
- 想让 AI 帮忙把文字、照片、健康记录、喂养睡眠等信息整理成档案。
- 使用 QClaw / OpenClaw / WorkBuddy / Codex 等 Agent 工具的用户。

## 系统能力

| 模块 | 能力 |
|---|---|
| 微信式记录 | 像聊天一样发一句话、发照片，AI 先回复“收到”，再慢慢整理 |
| 成长日记 | 自动生成每日标题、故事、标签和封面照片建议 |
| 照片资产库 | 所有照片统一入库，其他记录只引用照片，便于迁移和导出 |
| 成长时间轴 | 记录第一次、重要成长节点、家庭记忆和阶段变化 |
| 喂养 / 睡眠 / 尿片 | 适合 0-1 岁早期高频记录，后续可按需减少 |
| 健康档案 | 保存就医、疫苗、体检、报告照片和观察跟进 |
| 育儿知识推送 | 按月龄和敏感期推送轻量知识，并映射到自己孩子身上 |
| 待办提醒 | 记录买奶粉、买尿片、预约体检、观察大便等育儿待办 |
| 旧资料导入 | 旧照片、旧日记、Excel、飞书、其他育儿 App 导出先扫描再确认 |
| 扩展 Skills | 后续可扩展宝宝用品选购、孩子学习建议、成长报告、照片墙等能力 |
| 本地 / 飞书 | 可先本地保存，以后再同步到飞书多维表格或双备份 |

## Community

Community 基础技能会公开在 GitHub，用户确认后可以直接安装。当前 GitHub 仓库里实际带完整技能包的公开技能有 2 个：

- `child-growth-os`：晖爸育儿系统主控助手
- `archive-operator`：育儿资料操作员，用于旧资料导入、照片整理、时间轴和导出

安装主控助手：

```text
请安装晖爸育儿系统主控助手：
https://github.com/genlance/child-growth-os-knowledge/tree/main/skills/child-growth-os
```

安装成功后，如果 Agent 没有自动开始引导，请继续发送：

```text
开始使用晖爸育儿系统
```

第一次使用也可以直接说：

```text
我是第一次使用，先帮我建立孩子成长档案。
```

## 快速开始

新手建议先选择本地轻量版，把孩子资料放在非系统盘：

```text
1，D盘
```

也可以回复：

```text
1，E盘
```

确认保存位置后，系统会创建类似这样的资料夹：

```text
D:\ChildGrowthOS/
├── ChildGrowthOS.xlsx
├── data/
├── photos/
├── imports/
├── exports/
└── logs/
```

其中：

- `ChildGrowthOS.xlsx` 是给家长打开查看的表格。
- `data/` 是给 Agent 后续整理、同步和生成报告使用的数据。
- `photos/` 保存孩子照片和视频资产。
- `imports/` 存放旧资料扫描和待确认结果。
- `exports/` 存放时间轴、照片墙、报告等导出成果。

注意：确认保存位置前，Agent 不应该创建任何资料夹。孩子资料不建议默认放 C 盘，也不应该先创建在 Agent 工作区再迁移。

如果你发现资料夹里只有 `data/` 和 JSON，没有 `ChildGrowthOS.xlsx`，可以说：

```text
请帮我补建 ChildGrowthOS.xlsx，并把已有记录同步进去。
```

## 微信 / QClaw / 飞书

推荐落地方式：

```text
微信 / ClawBot
    ↓
QClaw 晖爸育儿系统
    ↓
本地 ChildGrowthOS 档案
    ↓
飞书多维表格同步（可选）
```

当微信消息进入系统时，Agent 应以微信真实发送时间为准，解释“今天 / 昨天 / 明天”，并保存消息 ID、发送时间和去重键，避免把旧消息重复写入。

如果你已经有飞书多维表格，系统应优先沿用旧表，先生成字段差异清单，确认后再补字段或新建缺失子表。

## 每日推送

默认推送节奏：

- 每天 `11:30`：1 条轻量育儿知识。
- 每天 `21:00`：当天成长日记复盘。
- 每月：按孩子出生日期每满一个月当天 `20:30`，推送一次本月育儿知识概览。

你可以通过微信直接修改：

```text
以后每天育儿知识改成早上9点发。
```

```text
晚上复盘改成22点。
```

## 旧资料导入

支持导入：

- 旧照片文件夹
- 微信聊天记录导出
- Word / Markdown / TXT 日记
- Excel / CSV 成长记录
- 飞书导出
- 手机相册整理包
- 其他育儿 App 导出的喂养、睡眠、尿片、身高体重、健康记录

导入不会直接写入正式档案。系统会先扫描并生成待确认清单。旧照片导入时，优先生成本地照片故事填写页：左边看照片，右边补日期、人物、地点、故事、标签、情绪和是否导入。

你可以这样说：

```text
这是我以前整理的照片文件夹：D:\OldBabyPhotos。请只扫描，先给我待确认清单，不要直接导入。
```

## 数据与安全

- 孩子照片、成长日记和健康资料默认保存在你自己的电脑或你自己的飞书里。
- 本 GitHub 仓库只保存公开知识库、技能说明和模板，不保存客户私人数据。
- 技能更新不会覆盖你的成长记录、照片、表格和本地资料。
- 医疗内容只做记录和提醒，不替代医生诊断。
- 发热、过敏、呼吸困难、脱水、抽搐、外伤等情况，请及时咨询专业医生或就医。
