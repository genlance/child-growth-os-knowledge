# 子技能分发协议

本协议用于 child-growth-os 主控技能从 GitHub 仓库发现、推荐、安装和更新子技能。

## 分层

```text
主控技能包：QClaw / WorkBuddy 初次安装，用于记录、飞书写入、微信触达、检查更新。
GitHub Hub：child-growth-os-knowledge，存放知识、版本、子技能 manifest。
子技能：english、blueprint、montessori 等按年龄/场景启用。
微信触达：通知用户有新知识、新技能或技能更新。
```

## 自动与确认边界

可以自动：

- 检查 `version.json`。
- 检查 `releases/latest.json`。
- 拉取知识卡片、月龄索引、敏感期索引。
- 在飞书记录“发现了新版本/新技能”。

必须用户确认：

- 安装新技能。
- 升级已安装技能。
- 启用会新增表字段、自动任务或外部权限的能力。
- 迁移旧数据结构。

## 微信推荐模板

```text
我发现「家庭英语启蒙规划与管理教练」已经适合小晖当前阶段。

它可以帮你：
1. 制定家庭英语输入计划
2. 选择适合月龄/年龄的绘本和音频
3. 把英语启蒙记录写回 child-growth-os

是否安装？
回复：安装英语启蒙
```

## 安装流程

1. 读取 `skills-manifest.json`。
2. 根据宝宝月龄、当前状态、用户问题匹配可推荐技能。
3. 微信发送推荐，等待用户确认。
4. 用户确认后，下载对应 `skills/{id}/`。
5. 安装到目标平台的技能目录或按平台要求导入。
6. 写入飞书 `已安装子技能` 记录。
7. 发送安装完成提示和示例用法。

## 更新流程

1. 每月或用户手动触发时读取 `releases/latest.json`。
2. 对比本地/飞书记录里的已安装技能版本。
3. 如果有新版，先展示 changelog。
4. 用户确认后再更新。
5. 更新后写入版本记录。

## 状态表建议

在飞书新增 `已安装子技能` 表：

- 技能ID
- 技能名称
- 当前版本
- 推荐年龄
- 安装状态
- 安装时间
- 上次检查时间
- GitHub路径
- 权限说明
- 用户确认记录
- 备注
