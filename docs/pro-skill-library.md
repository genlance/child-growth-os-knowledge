# 晖爸育儿 Pro 技能库

本项目提供 Community 基础能力，也会持续规划 Pro Skills。

Community 部分会在 GitHub 公开发布，适合完成孩子成长记录、照片归档、基础资料整理、旧资料导入等通用能力。

Pro Skills 是在 Community 数据基础上的扩展能力，适合更完整的成长创作、专题整理和长期规划。GitHub 仅展示功能介绍、适用场景与使用示例，完整技能包不在本仓库公开发布。

## Pro Skills 示例

- 成长照片墙
- AI 成长纪念册
- 宝宝月度 / 年度成长报告
- 宝宝成长视频
- 高级照片整理
- 英语启蒙规划
- 蒙氏观察与家庭环境建议
- 3-18 岁成长蓝图
- 系统育儿知识分析

## 获取方式

如需了解或获取 Pro Skills，请在公众号 / 小红书 / 抖音搜索：

```text
晖爸育儿代码
```

高级技能包、使用教程和后续更新会统一收录于「晖爸育儿 Pro 技能库」。

拿到 ZIP 技能包后，可以把 ZIP 发给你的 Agent，并告诉它：

```text
帮我安装这个技能包，并检查是否安装成功。
```

## 说明

- Pro Skills 是 Community 能力的扩展，不影响基础技能的公开使用。
- 本仓库不会保存用户的孩子照片、成长日记、飞书数据或本地资料。
- 用户自己的育儿数据仍保存在自己的本地资料夹或自己的飞书多维表格中。
- 医疗健康相关内容只作为记录和科普辅助，不替代医生或专业医疗建议。
